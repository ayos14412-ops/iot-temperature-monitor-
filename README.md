# Python-Based IoT Temperature Monitoring System

## Project Overview
This project simulates an Internet of Things (IoT) temperature monitoring system using Python, logging sensor data, handling anomaly values, and generating visual analytics.

## Files Included
- `iot_temperature_monitor.py`: Main Python script for data simulation, cleaning, analysis, and visualization.
- `temperature_readings.csv`: Simulated IoT temperature dataset containing 50 timestamped readings with exception handling cases.
- `temperature_graph.png`: Generated visual chart plotting sensor temperatures against the warning threshold.
- `README.md`: Project documentation.
